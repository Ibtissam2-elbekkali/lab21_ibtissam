# Lab21— Ibtissam

Une application Android native conçue pour explorer, surveiller et visualiser les données des capteurs de votre smartphone en temps réel.

##  Fonctionnalités
- **Liste des Capteurs** : Affichage de tous les capteurs disponibles sur l'appareil.
- **Capteurs de Mouvement** : Suivi précis de l'accéléromètre et du gyroscope.
- **Compteur de Pas** : Utilisation du capteur de reconnaissance d'activité pour compter les pas.
- **Visualisation Graphique** : Graphiques dynamiques en temps réel utilisant **MPAndroidChart**.
- **Interface Moderne** : Navigation fluide via des Fragments et Material Design.

##  Technologies utilisées
- **Langage** : Java
- **UI/UX** : Material Design, Navigation Component, ConstraintLayout
- **Graphiques** : MPAndroidChart
- **Permissions** : Gestion de l'Activity Recognition

##  Installation
1. Cloner le projet : `git clone`
2. Ouvrir avec **Android Studio**.
3. Synchroniser avec Gradle.
4. Lancer sur un appareil physique (recommandé pour tester les capteurs).
